# Urmi Text Tools

Конвертеры письменностей и очистка текста для христианского урмийского.

Интерфейс — тот же пастельный HTML-сайт (не стандартные виджеты Streamlit).

## Streamlit Cloud

1. Загрузите эту папку в GitHub-репозиторий `urmi-text-tools`.
2. [share.streamlit.io](https://share.streamlit.io) → **New app**.
3. Main file: `streamlit_app.py`.
4. Deploy. После обновления файлов нажмите **Reboot** у приложения.

## Локально

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Страницы

- Конвертеры (главная)
- Очистка текста (Cleaner в меню Streamlit; в самом сайте — вкладка в шапке)

Знак `+` всегда сохраняется.
